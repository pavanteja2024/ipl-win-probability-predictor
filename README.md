# IPL Win Probability Predictor

This project predicts the win probability of IPL matches using Machine Learning.

## Features Used
- Runs Left
- Balls Left
- Wickets Left

## Model
- Logistic Regression
- Achieved ~69% accuracy

## How to Run

1. Install required libraries:
pip install pandas numpy scikit-learn

2. Run the script:
python3 project.py
